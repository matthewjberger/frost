# The Frost book

The documentation for [Frost](https://github.com/matthewjberger/frost), built
with [mdBook](https://rust-lang.github.io/mdBook/). Everything under `src/` is
the source; `book/` is the rendered output and is not committed.

```bash
cargo install mdbook
just serve
```

`just build` renders once, `just watch` rebuilds on every change.
